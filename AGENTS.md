# Project Instructions

## Technology and dependencies

- Use Python 3.12 or newer.
- Declare project dependencies in `requirements.txt`. Do not create a `pyproject.toml`.
- Use the repository's `.venv/` for all Python commands and dependency installation; do not use the system Python environment.
- Use `mcp[cli]` for the MCP SDK and CLI.
- Add other third-party dependencies only when needed, and record them in `requirements.txt`.

## Project context

- This is a local MCP Odoo server.
- Keep Odoo credentials out of version control.
- Whenever the specification changes, update the README.md accordingly.
